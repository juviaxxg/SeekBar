# 寻径（SeekBar）

寻径是用 Python 和 AppKit 编写的 macOS 菜单栏工具。双击 Command（⌘）可以打开文件与应用搜索。寻径也支持在当前打开／存储窗口中快速切换目录。

## 安装与启用

1. 打开 `dist/SeekBar-0.1.5-arm64.pkg`，按 macOS 安装器提示将 `SeekBar.app` 安装到「应用程序」。这个安装包随附运行所需的 Python。当前构建适用于 Apple 芯片 Mac，使用的 Python 运行时要求 macOS 26.3 或更新版本。
2. 从「应用程序」打开「寻径」或 `SeekBar`。首次启动会打开权限设置，点击「桌面」「文稿」或「下载」检查并请求相应位置的文件读取权限。
3. 在同一窗口启用辅助功能（用于文件夹栏）和输入监控（用于双击 Command），并在 macOS 中确认。完全磁盘访问是可选的系统设置入口。需要时可从菜单栏重新打开权限设置。如果全局快捷键尚未生效，可从搜索窗口点击「启用 ⌘ ⌘…」，在系统「输入监控」设置中允许寻径，按系统提示重新打开应用。

从 0.1.4 起，应用使用本机专用签名。首次从临时签名迁移时，macOS 可能要求重新确认权限。以后用同一身份打包更新可沿用相同的签名识别规则。本地安装包未经过 Apple 公证。

## 快速切换目录

打开 Finder 或应用的打开／存储窗口，寻径会在窗口下方显示两行。上方可直接搜索本地文件夹，下方显示上次打开的文件夹。右侧下拉按钮可以选择任意匹配项，也可以浏览其他文件夹。搜索框为空时，下拉列表显示最近和常用文件夹。多个匹配结果也可用 ↑↓ 切换，按回车跳转。窗口下方空间不足时，搜索栏会显示在上方。

支持标准 macOS 打开／存储窗口，以及带可识别文件列表和操作按钮的自定义对话框。WPS 本地路径通过其地址栏跳转。其他自定义窗口的跳转取决于应用提供的导航方式。菜单栏可关闭 Finder 或整个文件夹栏。

## 搜索和结果操作

| 操作 | 用法 |
| --- | --- |
| 打开搜索 | 快速轻按两次 `Command`，也可从菜单栏打开 |
| 切换到文件搜索 | 搜索窗口处于焦点时，再轻按两次 `Command` |
| 指定结果类型 | 点击「应用」「文件夹」「文件」 |
| 按扩展名过滤 | 搜索如 `报告 ext:pdf` |
| 打开结果 | `Return`，或双击 |
| 在 Finder 显示 | `⌘Return` |
| 快速预览 | `⌘P` |
| 将目录应用到原窗口 | 选择文件夹后按 `⌘G`，适用于 Finder 和标准文件对话框 |
| 复制路径、收藏 | 搜索结果的「操作…」或右键菜单 |

文件名搜索使用系统 Spotlight 索引。当索引缺少精确匹配时，应用会在桌面、文稿、下载或已指定的搜索范围内补查文件名。没有文件夹访问权限时，应用会提示检查权限。也可以直接输入完整路径。本版本的搜索覆盖文件名，应用支持模糊匹配，Windows 文件管理器集成、网页搜索和自定义系统命令超出当前实现范围。

## 从源码构建

在 Mac 上准备 Python 3.12 或以上，以及 Xcode 命令行工具，首次在本机运行 `./setup-local-signing.sh`，以后运行 `./build-macos.sh`。签名身份保存在用户目录的 `Library/Application Support/SeekBar Signing`，请保留该目录以便继续签署更新。打包脚本在身份缺失时会停下来，避免无意中换签名。构建使用本机架构，`dist/` 只输出 `.pkg`。打包时的应用副本用完即清理。安装器固定覆盖 `/Applications/SeekBar.app`。安装包支持的最低系统版本取决于参与打包的 Python 运行时。

运行 `python3 -m unittest discover -s tests -v` 检查快捷键状态机和搜索。安装后可用 `/Applications/SeekBar.app/Contents/MacOS/SeekBar --self-test` 检查打包运行时，通过 `--ui-self-test` 验证原生搜索窗口和应用自带文件选择器内的目录跳转。
